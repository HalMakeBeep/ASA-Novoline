[HIGH] DLL protection — prevent unauthorized use — DONE
  - Option A: Embed encrypted DLL inside launcher EXE
    * DLL stored as encrypted resource in PrismeASA.exe
    * Decrypted in memory only after auth key validation
    * Never written to disk decrypted
    * If someone extracts ASA-Internal.dll alone, it won't work
  - Option B: Require auth handshake at DLL init
    * DLL checks for a shared memory token set by launcher
    * No token = DLL refuses to initialize
    * Simpler but DLL file still exists on disk
  - Option C: VMProtect/Themida on the DLL
    * Commercial code protection/obfuscation
    * Makes reverse engineering much harder
  - Recommendation: A + B combined (encrypted in EXE + runtime auth check)
